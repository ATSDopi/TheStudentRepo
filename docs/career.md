# 💼 Career, internships & interview prep

## 🎓 Student programs & paid fellowships — application required

| Program | What you get | Verify via | Link |
|---|---|---|---|
| ⭐ **Google Summer of Code** | **Paid** open-source stipend (~$1,500-3,000) | Application | [summerofcode.withgoogle.com](https://summerofcode.withgoogle.com) |
| **MLH Fellowship** | Open-source fellowship program | Application | [fellowship.mlh.io](https://fellowship.mlh.io) |
| **LFX Mentorship** | **Paid** Linux Foundation mentorships | Application | [mentorship.lfx.linuxfoundation.org](https://mentorship.lfx.linuxfoundation.org) |
| **Outreachy** | Paid FOSS internships for underrepresented groups | Application | [outreachy.org](https://www.outreachy.org) |
| **GitHub Campus Experts** | Community leadership + swag + network | GitHub student status + application | [education.github.com/experts](https://education.github.com/experts) |
| **Company student programs** | Microsoft Explore, Google STEP, Meta University, Amazon Future Engineer — early-year internships | Enrollment + application | company career sites |
