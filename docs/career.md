# 💼 Career, internships & interview prep

## CV & resume — free

| Tool | What you get | Link |
|---|---|---|
| ⭐ **FlowCV** | Free unlimited resume builder, no watermarks | [flowcv.com](https://flowcv.com) |
| **Reactive Resume** | Open-source resume builder | [rxresu.me](https://rxresu.me) |
| **OpenResume** | Free open-source builder + ATS checker | [open-resume.com](https://open-resume.com) |
| **Europass** | Official EU CV format, free editor | [europa.eu/europass](https://europa.eu/europass/en) |
| **Overleaf free** | LaTeX resumes/CVs (great tech templates) | [overleaf.com](https://www.overleaf.com) |
| **Canva / Google Docs templates** | Free resume templates | [canva.com](https://www.canva.com) |

## Interview prep — free

| Resource | What you get | Link |
|---|---|---|
| ⭐ **NeetCode** | Free curated problem roadmap + video solutions | [neetcode.io](https://neetcode.io) |
| **LeetCode** | Free problem bank (weekly contests) | [leetcode.com](https://leetcode.com) |
| **Grind 75 / Blind 75** | The classic must-do problem lists | [grind75.com](https://www.techinterviewhandbook.org/grind75/) |
| **Tech Interview Handbook** | Free complete guide (resume → offer) | [techinterviewhandbook.org](https://www.techinterviewhandbook.org) |
| **System Design Primer** | The reference free system-design repo | [github.com/donnemartin/system-design-primer](https://github.com/donnemartin/system-design-primer) |
| **HackerRank / CodeSignal** | Free practice — also used for real company assessments | [hackerrank.com](https://www.hackerrank.com) |
| **Pramp-style mock interviews** | Free peer mock interviews (Exponent, interviewing communities) | search "free mock interview" |
| **levels.fyi** | Real salary data — negotiate informed | [levels.fyi](https://www.levels.fyi) |
| **Glassdoor** | Interview reviews & salaries | [glassdoor.com](https://www.glassdoor.com) |
